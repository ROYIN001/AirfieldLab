# 7. ล้อและพื้น: โช้ค oleo ยาง เบรก การเลี้ยว และทางวิ่งเปียก

← [กลับไปหน้ารวมรอบที่ 1](../01-flight-physics.md) · [schema พารามิเตอร์](schema.md)

> ความเชื่อมั่นโดยรวม: กลาง (กฎและสมการทางวิ่งเปียก: สูง · ค่าโช้คและยางของเครื่องฝึกสมมุติ: ต่ำ เพราะเป็นค่าที่ออกแบบเอง) · แหล่งหลัก: NACA Rep. 1154 [G8], 14 CFR 23.473/25.473/25.109 [G3, G1, G6], FAA AC 25-32 [G13], NASA TN D-2056 / TN 4110 [G10, G9]

## 7.0 สรุปสั้น
- **โช้คปัจจุบันเป็นสปริงเชิงเส้นกับ damper เชิงเส้น ทำให้แรงสูงสุดเกิดทันทีที่ล้อแตะพื้น (t = 0) และสูงเกินจริง** ลองปล่อยตกที่ 3 m/s (590 fpm) แรงต่อล้อหลักข้างหนึ่งขึ้นเป็น 37.4 kN ในเฟรมแรก (ground reaction factor 3.39) เพราะเทอม c·v = 12,500 × 3 ไม่ต้องรอระยะยุบเลย ในโช้ค oleo แรงไฮดรอลิกแปรตามกำลังสองของความเร็วยุบและยางต้องยุบก่อน [G8] แรงจึงค่อย ๆ ขึ้น แบบจำลองที่เสนอ (สปริงก๊าซ polytropic + orifice damping กำลังสอง + ยางต่ออนุกรม) ให้ค่า 1.98 ที่ 58 ms ในโมเดล 6-DOF ตัวเดียวกัน (ค่าประมาณ เพราะพารามิเตอร์ของโช้คเป็นค่าประมาณ) และแรงล้อหลักหลัง step แรกเหลือ 0.73 W_st จาก 3.91 W_st (ตัวเลขหลังแก้ code ให้ damping ของยางไม่เกินแรงสปริงยาง ดู 7.2)
- **ยางด้านข้างผูกกับ "ความเร็ว" ไม่ใช่ "มุม slip"** สูตร `0.65·tanh(v_side/0.35)` ทำให้ cornering stiffness เท่ากับ 9.3 /rad ที่ 5 m/s (9.7 kt) และกลายเป็น 55.7 /rad ที่ 30 m/s (58.3 kt) ส่วนยางเครื่องบินจริงอยู่ราว 3.2 /rad และไม่ขึ้นกับความเร็ว [G9] ผลคือเครื่องบิน "เกาะราง" ตอนแตะพื้นแบบ crab และไม่มี relaxation length
- **ไม่มีสภาพผิวทางวิ่งเลย** ทั้งเบรกและแรงด้านข้างใช้ค่าเดียวกันทุกสภาพ ขณะที่ AIP/CAAT ใช้ GRF (RWYCC 0–6) มาตั้งแต่ 4 พ.ย. 2021 [G17] ส่วนดอนเมืองมีฝนเขตร้อนเป็นภัยหลัก จึงควรทำ μ(V, RWYCC) จากสมการ 14 CFR 25.109(c) [G6] และตาราง AC 25-32 [G13] และใส่ hydroplaning ที่ V_P = 9√p kt [G10] ยางหลัก 60 psi ของเครื่องฝึกจะ hydroplane ที่ 70 kt (36 m/s) ซึ่ง**ต่ำกว่าความเร็วแตะพื้น 85 kt (43.7 m/s)** เป็นบทเรียนที่เครื่องจำลองควรสอนได้
- **จอดแล้วไหล** เครื่องที่จอดเหยียบเบรกเต็มยังไหลไปช้า ๆ 0.012 m/s (0.023 kt หรือ 12 cm ใน 10 s) เพราะแรง idle 518 N ไปเจอแรงเสียดทานแบบ `tanh(v/0.25)` ซึ่งต้องมีความเร็วก่อนถึงจะเกิดแรง แก้ได้ด้วย state "ขนยาง" (bristle/relaxation) ที่ทำหน้าที่เป็นแรงเสียดทานสถิตไปพร้อมกัน
- **สิ่งที่ควรสร้างตามลำดับ:** (1) โช้คแบบอนุกรมที่มี stroke เป็น state ใน RK4 (2) ยางด้านข้างแบบ slip-angle พร้อม relaxation และวงกลมแรงเสียดทาน (3) μ(V, RWYCC) + hydroplaning + เบรกแยกซ้ายขวาพร้อมตรรกะล้อล็อก (4) ล้อหน้าเลี้ยวด้วยแป้น ±12° ผสมกับ caster ส่วน spin-up, อุณหภูมิเบรก และ autobrake ทำทีหลังได้

## 7.2 โช้ค oleo-pneumatic: ฟิสิกส์ กฎการรับรอง และค่าที่เสนอ

**ฟิสิกส์** โช้ค oleo ประกอบด้วยห้องก๊าซ (ไนโตรเจนหรืออากาศ) ทำหน้าที่เป็นสปริง และน้ำมันที่ถูกบีบผ่านรู orifice ทำหน้าที่เป็น damper ที่แปรตามกำลังสองของความเร็ว Milwitzky และ Cook [G8] เขียนแรงในแนวแกนโช้คเป็นผลรวมของสามเทอม (แรงก๊าซ, แรงไฮดรอลิก และแรงเสียดทานที่บุชกับซีล) แล้วเทียบกับ drop test ได้ตรงกันดี ทั้งกรณีที่ยางไม่ถึงก้นและกรณีที่ยางถึงก้น

แรงก๊าซ (polytropic):
$$F_a(s)=p_0A_a\left(\frac{V_0}{V_0-A_a s}\right)^{n}$$
โดย $s$ = ระยะยุบของโช้ค (m, บวกเมื่อยุบ, ตามแกน z ของ body ที่ชี้ลง), $p_0$ = ความดันก๊าซเมื่อยืดสุด (Pa), $A_a$ = พื้นที่ลูกสูบที่อัดก๊าซ (m²), $V_0$ = ปริมาตรก๊าซเมื่อยืดสุด (m³), $n$ = เลขชี้กำลัง polytropic NACA 1154 ใช้ "an average value of the effective polytropic exponent n=1.12" ในการเทียบกับ drop test [G8] ส่วนการยุบช้า ๆ ตอนจอดใกล้ isothermal ($n$ = 1)

แรงไฮดรอลิก (orifice):
$$F_h=\frac{\rho A_h^{3}}{2\,(C_dA_n)^{2}}\,\dot s\,|\dot s| \equiv K_h\,\dot s|\dot s|$$
$\rho$ = ความหนาแน่นน้ำมัน (kg/m³), $A_h$ = พื้นที่ไฮดรอลิกที่ดันน้ำมัน (m²), $A_n$ = พื้นที่สุทธิของรู orifice (m², รูลบด้วยพื้นที่ metering pin), $C_d$ = สัมประสิทธิ์การไหล NACA 1154 อ้างค่า "C_d equal to 0.9" [G8] (ข้อความจาก OCR ของสแกนรายงาน รูปสมการตรงกับตำราทั่วไป ความเชื่อมั่นกลาง) ในเครื่องจำลองให้ใช้ $K_h$ ค่าเดียวพอ และให้ขาคืนตัวใช้ $K_r$ ที่ใหญ่กว่า (rebound orifice เล็กกว่า) **metering pin** คือการทำให้ $A_n$ เปลี่ยนตาม $s$ เพื่อให้แรงแบนตลอดระยะยุบ ใส่เป็นตาราง $A_n(s)$ ได้ภายหลัง (P3)

แรงเสียดทานในโช้ค: NACA 1154 จำลองเป็น Coulomb ที่บุช แต่ในการเทียบ drop test "friction forces in the shock strut were assumed to be negligible" [G8] เราจึงตั้งเป็นศูนย์ (ตัวเลือก $F_f=\mu_f|F_a|\operatorname{sign}\dot s$, $\mu_f$ 0.02–0.05 ยังไม่ยืนยัน) ส่วนยาง NACA 1154 ใช้ $F_v=m'z^r$ เป็นช่วง ๆ [G8] เราใช้สปริงเชิงเส้นกับ damping เล็กน้อย (7.3)

**กฎการรับรองที่ใช้เป็นเป้าในการออกแบบ** (ตัวเลขจากข้อความกฎที่เปิดอ่าน)

**ค่าที่ได้สำหรับเครื่องฝึก** (`g7_oleo.mjs`): $W/S$ = 4,960 lb / 175.5 ft² = 28.3 lb/ft² ให้ $V$ = 10.15 fps แล้วจำกัดที่ **10 fps = 3.048 m/s** ส่วน drop height = 19.1 นิ้ว จำกัดที่ 18.7 นิ้ว ให้ $v=\sqrt{2gh}$ = 3.052 m/s (สองข้อสอดคล้องกัน) และ reserve = 3.66 m/s (12 fps) สำหรับเกณฑ์ในเครื่องจำลอง: แตะพื้นแรงกว่า 600 fpm (10 fps) ถือว่าเกินขีดออกแบบ ("hard landing" ต้องตรวจโครงสร้าง) แรงกว่า 720 fpm (12 fps) เกินพลังงานสำรองของขา ส่วนเกณฑ์ crash เดิมที่ 900 fpm ยังเก็บไว้ได้ (การแบ่งชั้นนี้เป็นการตีความของเราเอง ค่าประมาณ)

**การ implement ที่แนะนำ (โมเดลอนุกรม, มวลล้อเป็นศูนย์)** ใช้ stroke $s_i$ ของแต่ละขาเป็น state ใน RK4 (`x[13..15]`) ยางกับโช้คต่ออนุกรม แรงในยางเท่ากับแรงในโช้ค จึงแก้หา $\dot s$ แบบปิดได้:
$$k_t(\delta_{pen}-s)+c_t(\dot\delta_{pen}-\dot s)=F_a(s)+K\dot s|\dot s|+c_l\dot s$$
โดย $\delta_{pen}$ = ระยะที่ล้อ (ตำแหน่งยืดสุด) จมลงในพื้น (m), $k_t, c_t$ = ความแข็งและ damping ของยาง, $K = K_h$ เมื่อ $\dot s \ge 0$ หรือ $K_r$ เมื่อคืนตัว, $c_l$ = เทอมเชิงเส้นเล็ก ๆ ที่ทำให้ราก $\dot s$ เรียบรอบจุดสมดุล (ถ้า $c_l$ = 0 อนุพันธ์ของ $\sqrt{\cdot}$ จะเป็นอนันต์ที่จุดสมดุล ทำให้ RK4 สั่น)
```js
// per strut i, inside deriv(s, out): pen and penDot along the ground normal, sI = s[13+i]
function strutStep(P, pen, penDot, sI) {
  const sc = Math.min(Math.max(sI, 0), 0.995 * P.S);
  const Fa = P.p0 * P.A * Math.pow(P.L0 / (P.L0 - sc), P.n);       // L0 = V0/A
  const dl = pen - sI;                                               // tyre deflection
  const solve = (D) => { const K = D >= 0 ? P.Kh : P.Kr, a = Math.abs(D);
    const v = (-P.cl + Math.sqrt(P.cl * P.cl + 4 * K * a)) / (2 * K); return D >= 0 ? v : -v; };
  const Ft0 = dl > 0 ? P.kt * dl : 0;
  let sd0 = solve(Ft0 - Fa); if (sI <= 0 && sd0 < 0) sd0 = 0;        // top-out also in the predictor
  const damp = Math.max(-Ft0, Math.min(Ft0, P.ct * (penDot - sd0))); // |tyre damping| <= tyre spring force
  const N = dl > 0 ? Math.max(0, Ft0 + damp) : 0;                     // tyre hysteresis, no force step at contact
  let sd = solve(N - Fa);
  if (sI <= 0 && sd < 0) sd = 0;                                     // top-out
  if (sI >= P.S && sd > 0) sd = 0;                                   // bottomed: tyre carries the rest
  return { N, sd };
}
// after each RK4 step: x[13+i] = clamp(x[13+i], 0, S_i)
```
การตรวจทานพบว่า code ฉบับแรก (damping ยาง $c_t(\dot\delta_{pen}-\dot s)$ ไม่จำกัด และ $\dot s$ ตัวแรกไม่ถูกตัดที่ top-out) ทำให้ N กระโดดเป็น 1.19 W_st ทันทีที่ล้อแตะ (ปล่อยตก 3 m/s, `g7_review_t05.mjs`) ซึ่งเป็นข้อบกพร่องแบบเดียวกับโมเดลปัจจุบันแม้เล็กกว่า จึงแก้เป็นฉบับข้างบน: N ที่ 1 ms หลังแตะเหลือ 0.20 W_st และไม่มีขั้นกระโดด ($c_t$ = 0 ให้ 0.10 W_st)

พารามิเตอร์ต่อขา: $L_0 = S\,r_c/(r_c-1)$, $F_{ext} = W_{st}/r_s$, $p_0 = p_{static}/r_s$, $A = F_{ext}/p_0$ ($r_s$, $r_c$ ดู JSON) time constant ต่ำสุดรอบจุดจอด ≈ $c_l/(k_t+k_{gas})$ ≈ 5 ms เทียบกับ dt 4.17 ms ยังเสถียรสำหรับ RK4 (ทดสอบแล้วที่ 240 Hz ไม่สั่น)

แบบ 2-DOF ที่มีมวลล้อ (`g7_oleo.mjs`) มีโหมดล้อบนยาง ≈ 26 Hz ต้อง sub-step จึงไม่แนะนำสำหรับเบราว์เซอร์

**7.3.2 แรงตั้งฉาก** Smiley และ Horne [G9] ให้สูตรเชิงประจักษ์ของแรง–การยุบแบบไร้มิติ รูปที่อ่านได้ (OCR ไม่ชัด ความเชื่อมั่นต่ำ) คือ $F_z \approx 2.4\,(p+0.08p_r)\,w\sqrt{dw}\,(\delta/w - C_z)$ โดย $p$ = ความดันยาง (psi), $p_r$ = rated pressure, $w$ = ความกว้าง (in), $d$ = เส้นผ่านศูนย์กลาง (in), $\delta$ = การยุบ (in), $C_z$ = 0.03 สำหรับ Type III [G9, eq. 23–24] เมื่อแทน 6.50-8 ที่ 60 psi จะได้ความชัน 1,797 lb/in ≈ **315 kN/m** และการยุบที่โหลดสถิต ≈ 35 mm (สูตรมีค่าออฟเซ็ต $C_z$; สปริงเชิงเส้นของเราให้ 30 mm) เราใช้ $k_t$ = 320 kN/m (ล้อหน้า 160 kN/m สเกลตามขนาด) damping ของยาง $c_t$ = 3,500 N·s/m (ζ ≈ 0.1, ค่าประมาณ) รัศมีหมุนจริงใช้ $r_e \approx r-\delta_0/3$ [G9, eq. 66] ≈ 0.235 m

**7.3.3 แรงด้านข้าง: เปรียบเทียบตัวเลือก** มุม slip $\alpha=\operatorname{atan2}(v_s, |v_l|)$ โดย $v_l, v_s$ = ความเร็วจุดสัมผัสตามแนวและตั้งฉากกับระนาบล้อ (m/s) แรงด้านข้างหักล้างการไถลไปทางขวาของล้อ (ตามแกน y ของ FRD)

ทุกแบบมีต้นทุน CPU ต่ำมาก (3 ล้อ × 4 stage × 240 Hz)

**ค่าความแข็ง** จาก NACA TN 4110 [G9, eq. 82] cornering power $N_\psi = C_c\,(p+0.1p_r)\,w^2$ (lb/deg; หน่วยและเทอม 0.1 ตีความจาก OCR) กับ $C_c = 1.2(\delta/d)-8.8(\delta/d)^2$ เมื่อ $\delta/d \le 0.0875$ (สองช่วงของสูตรต่อกันพอดีที่ 0.0875 ทำให้มั่นใจว่าอ่าน OCR ถูก) แทนค่า 6.50-8 ที่ 60 psi, $\delta/d$ = 0.061 จะได้ $C_c$ = 0.0404 → 119 lb/deg = 30.3 kN/rad หารด้วยโหลด 9.5 kN ได้ **$C_\alpha' \approx$ 3.2 /rad (0.056 /deg)** ความเชื่อมั่นต่ำถึงกลาง ค่าความแข็งนี้ทำให้ที่มุม 5° ได้ $F_y/N$ = 0.27 และที่ 10° ได้ 0.48 (tanh)

**Relaxation length** แรงด้านข้างไม่เกิดทันทีเมื่อเปลี่ยนมุม slip ยางต้องกลิ้งไปได้ระยะหนึ่ง $L_r$ ก่อน TN 4110 ให้ $L_s=(2.8-0.8p/p_r)(1-c\,\delta/d)\,w$ [G9, eq. 43] แต่ค่า $c$ ใน OCR อ่านได้ทั้ง 0.55 และ 5.5 ทำให้ได้ 0.35 หรือ 0.24 m (การเปิดอ่านซ้ำในการตรวจทานเห็นเป็น ".55" จึงน่าจะเป็น 0.55 → 0.35 m แต่ยังไม่ได้เทียบกับภาพสแกน) เราใช้ **0.30 m** (ค่าประมาณ อยู่ระหว่างสองค่า) การ implement แบบ state ทำได้ดังนี้ เมื่อ $y$ = ระยะเบี่ยงด้านข้างของยาง (m):
$$\dot y = v_s - \frac{|v_l|}{L_r}\,y,\qquad F_y = -k_y\,y - c_y\,v_s\,[\text{ถ้ายังไม่ไถล}],\qquad k_y=\frac{C_\alpha}{L_r},\quad |y|\le \frac{\mu_y N}{k_y}$$
ในสภาวะคงตัว $y = L_r\tan\alpha$ จึงได้ $F_y = -C_\alpha\tan\alpha$ ที่ความเร็วศูนย์ $y$ กลายเป็นสปริงต้านการไถล (แรงเสียดทานสถิต) เอง การจำกัด $|y|$ ทำหลังแต่ละ step $k_y$ = 30.3 kN/rad / 0.30 m ≈ 101 kN/m, $c_y$ ≈ 9,900 N·s/m (ζ 0.5) ค่าลักษณะเฉพาะ $|v_l|/L_r$ × dt = 0.63 ที่ 45 m/s และ 0.97 ที่ 70 m/s ยังอยู่ในเขตเสถียรของ RK4 (< 2.78) YASim ใช้แนวคิดคล้ายกันคือสปริงแรงเสียดทานยาว 5 mm (`_fric_spring = 0.005f`) [G20]

**วงกลมแรงเสียดทาน** แรงเบรก $F_x$ กับแรงด้านข้างใช้แรงเสียดทานก้อนเดียวกัน: $F_y^{max}=\sqrt{\max\!\big(0,(\mu N)^2-F_x^2\big)}$ ถ้าล้อล็อก แรงทั้งหมดชี้สวนความเร็วไถล ทำให้เลี้ยวไม่ได้ ซึ่งเป็นเหตุผลที่ antiskid ช่วยรักษาการควบคุมทิศทาง [G12]

**7.3.4 แรงตามยาวและความต้านทานการหมุน** ล้อที่ไม่เบรกมีแรงต้านการหมุน $F_r=-\mu_r N\,\mathrm{sign}(v_l)$ $\mu_r$ = 0.02 บนผิวแข็งแห้งทั้งใน JSBSim c172p [G19] และ FlightGear (Asphalt 0.02, Gravel 0.04 และ 0.1 สำหรับ `ws30land` ซึ่งเป็นวัสดุพื้นดินทั่วไปของ WS3.0 ไม่ใช่ "หญ้า" หรือ "ดิน" โดยตรง; `friction-factor` Asphalt 1.0, Gravel 0.5, ws30land 0.7) [G21] เป็นค่าจากโมเดลเปิด ไม่ใช่การวัด (ความเชื่อมั่นต่ำ) ล้อที่เบรกหรือหยุดนิ่งใช้ state ตามยาว $x_b$ แบบ elasto-plastic: $\dot x_b = v_l$, $F_x=-k_x x_b - c_x v_l$, $|x_b|\le F_{max}/k_x$ โดย $F_{max}$ = แรงเบรกที่ได้ (7.4) บวก $\mu_r N$ เมื่อปล่อยเบรก $F_{max}$ เหลือแค่ $\mu_r N$ ล้อจึงกลิ้งไปได้ ความแข็งตามยาว $K_x \approx 1.2\,p\,d$ (lb/in) ที่ rated [G9, eq. 52] เราแทนด้วยความดันใช้งานแทน rated (ค่าประมาณ): 1.2 × 60 × 19.5 = 1,404 lb/in ≈ **246 kN/m** แรง idle 518 N จึงทำให้ $x_b$ ยุบราว 1 mm แล้วหยุด ปัญหาจอดแล้วไหลหายไป

**7.3.5 Spin-up ตอนแตะพื้น (ทางเลือก แต่มีผลกับการเด้ง)** ล้อที่แตะพื้นด้วยความเร็ว $V$ ต้องเร่งจาก 0 ถึง $\omega = V/r_e$ แรงลากระหว่างนั้น ≈ $\mu N$ (Part 25 ให้ใช้ μ ไม่เกิน 0.8 [G1, 25.473(e)]) ค่าประมาณสำหรับล้อหลัก: $I_w$ ≈ 0.33 kg·m², 85 kt, μ 0.6, N ≈ 0.3 W ต่อข้าง ได้ $t_{spin} = I_w\omega/(\mu N r_e)$ ≈ 66 ms อิมพัลส์รวม $2I_wV/r_e^2$ ≈ 523 N·s (V ลดแค่ 0.23 m/s) แต่กระทำต่ำกว่า CG ราว 1.5 m จึงให้ **อัตรา pitch ก้มประมาณ 6°/s** (`g7_misc.mjs`, ขอบบนเพราะไม่คิด springback) ช่วยให้ "ติดพื้น" แทนการกระโดด implement: $\omega_i$ เป็น state นอก RK4 ($\omega \leftarrow \min(\omega + \mu N r_e\,dt/I_w,\ V/r_e)$) และใส่แรง $-\mu N$ จนกว่า $\omega r_e = V$ ถ้าลงบนน้ำขังที่ความเร็วเกิน $7.7\sqrt p$ ล้ออาจไม่หมุนเลย [G11]

## 7.4 เบรก antiskid เบรกแยกข้าง autobrake และพลังงานเบรก

**แรงบิดเบรก** ต่อล้อ $i$: $T_{b,i}=\beta_i\,T_{max}$ โดย $\beta_i \in [0,1]$ คือความดันเบรกที่ผ่าน actuator แล้ว (ขึ้นด้วยอัตราจำกัด 2.5 /s เท่าโค้ดเดิม) แรงที่เบรก "ขอ" ที่พื้นคือ $F_{b,i}=T_{b,i}/r_e$ สำหรับเครื่องฝึกเราตั้ง $F_{b,max}$ = 0.6 × น้ำหนักสถิตบนล้อหลักข้างนั้น (5.7 kN, $T_{max}$ ≈ 1,350 N·m) เป็นค่าประมาณที่จงใจเลือกให้**ล็อกล้อบนแห้งไม่ได้** (μ_peak 0.8) แต่**ล็อกได้บนเปียกความเร็วสูง** (μ_peak 0.47 ที่ 59 kt) ซึ่งเป็นพฤติกรรมที่นักบินฝึกต้องเรียนรู้

**μ กับ slip** อัตราส่วนการไถล $\kappa=(V-\omega r_e)/V$ [G12, eq. 5] แรงเบรกขึ้นจาก 0 ที่ $\kappa$ = 0 ถึงสูงสุดที่ $\kappa_p$ แล้วลดลงสู่ค่าล้อล็อกที่ $\kappa$ = 1 ระบบ antiskid ของ NASA ที่ทดสอบควบคุม slip ไว้ที่ราว 0.15 (0.13 บนแห้ง ถึง 0.18 บนน้ำท่วม) วงรอบ 10–12 Hz และได้ค่าเฉลี่ยของ μ ที่ใช้จริงต่อ μ สูงสุดที่มี 0.94 บนแห้ง (ช่วง 0.79–1.00) และ 0.80 บนผิวชื้นและน้ำท่วม (ช่วง 0.47–0.94) [G12] สำหรับยางทดสอบ 40×14 type VII ที่ 140 psi รายงานใช้ μ สูงสุดบนแห้งที่ความเร็วต่ำราว 0.78 ซึ่งเป็นค่าทำนายเชิงประจักษ์สำหรับยางเย็นจากเอกสารอ้างอิงของรายงาน (ไม่ใช่ค่าวัดตรง) และสอดคล้องกับข้อมูล spin-down ช่วงแรก [G12] ส่วน FAA กำหนดประสิทธิภาพ antiskid ไว้ใช้คำนวณบนทางเปียก: on-off 0.30, quasi-modulating 0.50, fully modulating 0.80 [G6, 25.109(c)(2)] AC 25-32 ใช้ตัวคูณ 0.375 และ 0.625 เทียบกับระบบ fully modulating [G13] ซึ่งก็คือ 0.30/0.80 และ 0.50/0.80 สอดคล้องกันพอดี

**แบบจำลองที่เสนอ (quasi-static ไม่มี state ความเร็วล้อ)** เพราะ time constant ของการหมุนล้อภายใต้เบรก $\tau \approx I_wV/(r_e^2N\,\partial\mu/\partial\kappa)$ อยู่ที่ราว 3 ms ที่ 40 m/s (ค่าประมาณ: $I_w$ 0.33 kg·m², $r_e$ 0.235 m, N = W_st, $\partial\mu/\partial\kappa \approx 8$ คือ μ 0.8 ที่ κ ≈ 0.1) และยิ่งสั้นลงเมื่อความเร็วลดลง ซึ่งต่ำกว่า dt = 4.17 ms ของ RK4 ถ้าทำเป็น state ต้อง sub-step หลายเท่า จึงเลื่อนไป P3
```js
// per braked wheel, called in deriv() with N (strut force), vC (contact velocity, 2D), mu = surfaceMu(...)
function brakeForce(w, N, vC, mu, AS) {
  const Fcmd = w.beta * w.Fmax;                         // requested by pedal / autobrake
  if (AS.present) return { Fx: Math.min(Fcmd, AS.eff * mu.peak * N), locked: false };
  if (!w.locked && Fcmd > mu.peak * N && speed(vC) > 0.5) w.locked = true;   // wheel lock
  if (w.locked && (Fcmd < 0.9 * mu.skid * N || speed(vC) < 0.5)) w.locked = false;
  return w.locked ? { skid: mu.skid * N } : { Fx: Fcmd };   // skid: force opposes the whole contact velocity vector
}
```
เมื่อล็อก แรง $\mu_{skid}N$ ชี้สวนเวกเตอร์ความเร็วของจุดสัมผัสทั้งหมด จึงไม่มีแรงด้านข้างเหลือให้เลี้ยว (สอดคล้องกับวงกลมแรงเสียดทาน) อัตราส่วน $\mu_{skid}/\mu_{peak}$ ตั้ง 0.75 บนแห้งและ 0.5 บนเปียก (ค่าประมาณ ความเชื่อมั่นต่ำ; TM X-72650 อธิบายแค่เชิงคุณภาพว่าล้อล็อกบนเปียกเกิด reverted rubber และ "tire cornering capability drops to zero" [G11])

**เบรกแยกข้าง (differential toe brakes)** แยก `cmd.brakeL`, `cmd.brakeR` (และ `ac.brakeL/R`) ปุ่ม B ยังสั่งทั้งสองข้างได้เหมือนเดิม ส่วนปุ่มแยกข้างและ trigger ของ gamepad ให้ตกลงร่วมกับหัวข้ออินพุต โมเมนต์ yaw ที่ได้ = $(F_R-F_L)\cdot(\text{track}/2)$ เบรกข้างเดียวเต็มที่ขณะแท็กซี่ได้ 5.7 kN × 1.55 m ≈ 8.9 kN·m ใช้เลี้ยวแคบร่วมกับล้อหน้าแบบ caster (7.5)

**Autobrake (airliner รอบถัดไป)** โครงสร้าง: ระดับ → ค่าหน่วงเป้าหมาย $a^*$ → PI บน $(a^*-a_{meas})$ สั่ง $\beta$ ผ่าน antiskid เริ่มเมื่อล้อหลัก spin-up ยกเลิกเมื่อเหยียบเบรก ค่าหน่วงแต่ละระดับของ 737/A320 อยู่ในคู่มือที่ไม่เปิดสาธารณะ จึงยังไม่ใส่ตัวเลข (ยังไม่ยืนยัน) เกณฑ์ขั้นต่ำของ Part 25 คือค่าหน่วงเฉลี่ยของ design landing stop ไม่ต่ำกว่า 10 fps² (0.31 g) [G7, 25.735(f)]

**พลังงานและความร้อน (P3, ค่าประมาณทั้งหมด)** พลังงานจลน์ที่ 80 kt = 1.91 MJ ถ้า 85% เข้าเบรก จะได้ 810 kJ ต่อข้าง กับมวลเหล็ก 6 kg ($c$ ≈ 490 J/kg·K) ร้อนขึ้นราว 275 K ต่อการหยุดเต็มแรงหนึ่งครั้ง (810 kJ / (6 kg × 490 J/kg·K); `g7_misc.mjs` พิมพ์กรณี 3 kg ซึ่งได้ 551 K) แบบจำลอง $m c\,\dot T_b = F_b v_l - m c\,(T_b-T_{amb})/\tau_{cool}$ และคูณ $F_{b,max}$ ด้วย $\mu_{pad}(T_b)$ ที่เป็น 1 ต่ำกว่า 400 °C ลดเชิงเส้นถึง 0.6 ที่ 700 °C ใช้เพื่อให้ RTO ซ้ำ ๆ มีผล ไม่ได้อ้างว่าเป็นค่าของเบรกจริง

## 7.5 การเลี้ยวล้อหน้า: แป้น ไทลเลอร์ caster และ shimmy

| แบบ | การทำงาน | ตัวอย่างค่า | ใช้กับ |
|---|---|---|---|
| ล้อหน้าเชื่อมกับแป้นหางเสือ (pedal-linked) | มุมล้อ ∝ แป้นผ่านสปริง ไม่ขึ้นกับความเร็ว | JSBSim c172p `max_steer` 10° [G19] | เครื่องฝึก, C172 |
| caster อิสระ + เบรกแยกข้าง | ล้อหมุนตามทิศความเร็วเอง เลี้ยวด้วยเบรก | JSBSim ใช้มุมความเร็วล้อเป็นมุมเลี้ยวเมื่อ `max_steer` = 360 [G19] | เครื่องเบาบางแบบ (เช่น DA40 — ยังไม่ยืนยัน ตรวจรายแบบในรอบถัดไป) |
| ไทลเลอร์ + แป้น (ไฮดรอลิก) | ไทลเลอร์มุมใหญ่ที่ความเร็วต่ำ แป้นมุมเล็ก ลดตามความเร็ว | ค่าของ 737/A320 ยังไม่ยืนยัน (ACAPS ของ Boeing มีรูปมุมเลี้ยวในหัวข้อ turning radii แต่ดึงตัวเลขจากรูปไม่ได้) | airliner (รอบหลัง) |

**สิ่งที่ผิดตอนนี้** โค้ดให้ล้อหน้าเลี้ยวตามแป้นได้ถึง 35° ที่ความเร็วต่ำ (และ actuator ยอมถึง 40°) ผลวัดคือรัศมี 4.8 m ที่ 4.8 m/s และที่ 9.5 m/s (18 kt) ยังได้แรงเหวี่ยง 0.63 g หรือราว 70% ของขีดคว่ำ ขีดคว่ำสถิตของเราคำนวณจากระยะ CG ถึงเส้นล้อหน้า–ล้อหลัก 1.161 m และความสูง CG 1.30 m ได้ $a_y/g$ = 0.89 (turnover angle 48°, `g7_misc.mjs`) การลดความแข็งด้านข้างของยาง (7.3.3) ช่วยเฉพาะที่ความเร็วต่ำ ส่วนที่ความเร็วแท็กซี่สูง แรงเหวี่ยงถูกกำหนดด้วยมุมเลี้ยวเป็นหลัก (ดูผลแบบจำลองจักรยานด้านล่าง)

**ข้อเสนอสำหรับเครื่องฝึก (ค่าประมาณ ความเชื่อมั่นต่ำ)**
$$\delta_{cmd}=-\frac{\delta_r}{\delta_{r,max}}\,\delta_{ped},\quad \delta_{ped}=12^\circ,\quad |\dot\delta|\le 60^\circ/\mathrm s$$
รัศมีเลี้ยวรอบจุดกึ่งกลางเพลาหลัก $R \approx \text{wb}/\tan\delta$ = 2.65/tan 12° = **12.5 m** (10° → 15.0 m) ไม่ต้องลดตามความเร็ว เพราะเป็นกลไกแป้นกับสปริง ส่วนตัวลดตามความเร็วแบบเดิม (35° → 6°) ให้ย้ายไปเป็นพารามิเตอร์ของ airliner ที่มีไทลเลอร์ ข้อควรรู้ (ค่าประมาณจากแบบจำลองจักรยานกับยาง tanh $C_\alpha'$ 3.2 /rad, μ 0.8, `g7_review_steer.mjs`): แป้นสุด 12° ให้ R 12.7 m, $a_y$ 0.20 g ที่ 5 m/s แต่ที่ 10 m/s (19 kt) ได้ R 13.9 m, $a_y$ 0.73 g หรือ 82% ของขีดคว่ำ ซึ่ง**สูงกว่าโมเดลปัจจุบัน** (0.63 g ที่ 9.5 m/s) เพราะการบังคับเป็นแบบ neutral steer (ความแข็งต่อโหลดของล้อหน้าและหลังเท่ากัน) นี่เป็นพฤติกรรมจริงของล้อหน้าแบบแป้น นักบินจึงไม่เหยียบแป้นสุดที่ความเร็วแท็กซี่สูง ถ้าต้องการกันผู้ฝึกใหม่ ให้ ASSIST จำกัดมุมที่สั่งให้ $a_y \le 0.35g$: $\delta_{max}(V)=\arctan(\text{wb}\cdot0.35g/V^2)$ = 5.2° ที่ 10 m/s (ค่าประมาณ ไม่ใช่กลไกจริงของเครื่องบิน)
**โหมด caster:** ถ้าใช้เบรกแยกข้างต่างกันเกิน 0.2 หรือแรงด้านข้างที่ล้อหน้าเกินขีดสปริง ให้ล้อหน้าหลุดเป็น caster ภายใน ±45° โดยมุมล้อตามทิศความเร็วของล้อหน้าแบบ lag อันดับหนึ่ง:
$$\dot\delta=\frac{\operatorname{atan2}(v_{s,n},v_{l,n})-\delta}{\tau_s},\quad \tau_s=0.05\ \mathrm s$$
แรงด้านข้างของล้อหน้าเหลือแค่แรงต้านการหมุน ผลคือเลี้ยวแคบได้ด้วยการเบรกล้อในข้างที่จะเลี้ยว **Shimmy** (การสั่นตัวเองของล้อ caster จากความยืดหยุ่นของยาง) ไม่จำลองโดยตรง $\tau_s$ ทำหน้าที่แทน shimmy damper ห้ามจำลองล้อ caster ด้วยความเฉื่อยกับ trail จริงที่ 240 Hz โดยไม่มี damper เพราะจะเกิด shimmy เชิงตัวเลข

**ทางเปียกตาม 14 CFR 25.109(c)** สัมประสิทธิ์สูงสุดระหว่างยางกับพื้น (smooth wet) เป็นฟังก์ชันของความเร็วพื้น $V$ (kt) และความดันยาง [G6]:

ความดันอื่นใช้ interpolate เชิงเส้น แล้วคูณประสิทธิภาพ antiskid ตาม (c)(2) สำหรับทาง grooved หรือ PFC ใช้ 70% ของค่าแห้ง หรือสมการกำลังห้าใน (d)(2) (ใส่ไว้ใน JSON แล้ว; ที่ 50 psi ได้ 0.859 ที่ 0 kt และ 0.451 ที่ 80 kt สูงกว่าทางเรียบ 0.380 ตามคาด) หมายเหตุแหล่ง: PDF ของ govinfo แสดงสมการเป็นรูปภาพ ตัวเลขข้างบนอ่านจากหน้า LII ที่ถอดข้อความ eCFR [G6] ค่าที่ 60 psi (ล้อหลักของเรา, `g7_ground.mjs`): 0.867 ที่ 0 kt, 0.641 ที่ 30 kt, 0.470 ที่ 59 kt, 0.373 ที่ 80 kt, 0.352 ที่ 85 kt

**Hydroplaning** Horne และ Dreher ได้ $V_P \approx 9\sqrt{p}$ kt ($p$ เป็น psi) โดยสมมุติสัมประสิทธิ์แรงยกของน้ำใต้ยางราว 0.7 [G10, eq. 4] AC 25-32 และ EASA ใช้สูตรเดียวกันและเริ่มลด μ เหลือ 0.05 ตั้งแต่ 0.85 V_P [G13, G15] ยางที่ไม่หมุน (เช่นแตะพื้นแล้ว spin-up ไม่ได้) hydroplane ที่ $7.7\sqrt{p}$ [G11] ความลึกน้ำวิกฤติราว 0.1–0.4 นิ้ว (2.5–10 mm) ขึ้นกับดอกยางและผิวทาง ยางเรียบอาจเริ่มที่ 0.02–0.09 นิ้ว [G10, น. 10 และ 16] ระหว่าง hydroplaning แรงหน่วง "do not usually exceed 0.05" และแรงด้านข้างเล็กมากจนลมขวางราว 9 kt ก็เอาชนะได้ [G10, น. 13 และ น. 9, 11] ล้อเริ่มหมุนช้าลง (spin-down) ได้ตั้งแต่ความเร็วต่ำกว่า V_P [G10, น. 7–8]

| ยาง | p | $V_P = 9\sqrt p$ | $0.85V_P$ | $7.7\sqrt p$ (ไม่หมุน) |
|---|---|---|---|---|
| ล้อหน้า 5.00-5 | 45 psi | 60.4 kt | 51.3 kt | 51.7 kt |
| ล้อหลัก 6.50-8 | 60 psi | **69.7 kt** | 59.3 kt | 59.6 kt |
| ยาง airliner ตัวอย่าง | 200 psi | 127.3 kt | 108.2 kt | 108.9 kt |

**ฟังก์ชันที่ implement ได้** (ค่า μ ที่ "ยางทำได้สูงสุด" แยกจากประสิทธิภาพเบรก ใช้ร่วมกันทั้งแรงเบรกและแรงด้านข้าง)
```js
// surface = { rwycc: 6|5|4|3|2|1, depthMm, grooved }, psi = tyre pressure, Vkt = ground speed
function surfaceMu(Vkt, surface, psi) {
  const VP = 9 * Math.sqrt(psi), wet = mu109max(Vkt, psi, surface.grooved);   // 25.109(c)/(d)
  switch (surface.rwycc) {
    case 6: return { peak: 0.80, skidRatio: 0.75 };                // TN D-8455 / JSBSim, dry
    case 5: return { peak: wet, skidRatio: 0.5 };
    case 4: return { peak: 0.20 / 0.8, skidRatio: 0.5 };           // AC 25-32 values are achieved with eff 0.8
    case 3: return { peak: 0.16 / 0.8, skidRatio: 0.5 };
    case 2: return Vkt < 0.85 * VP ? { peak: Math.min(0.16, 0.5 * 0.8 * wet) / 0.8, skidRatio: 0.5 }
                                    : { peak: 0.05, skidRatio: 1.0, hydroplaning: true };
    case 1: return { peak: 0.08 / 0.8, skidRatio: 0.5 };
  }
}
```

## 7.7 สรุปการ implement ใน `src/20-flight.js`
1. **โครงพารามิเตอร์:** แทน `AC.gear` ด้วยออบเจ็กต์ `GEAR` ต่อแบบเครื่องบิน แต่ละขามี `b` (ตำแหน่งล้อเมื่อยืดสุด), `strut`, `tyre`, `brake` (ข้าง L/R หรือ null), `steer` (pedal/caster/tiller) และค่าระดับเครื่อง `antiskid` ส่วน `SURFACE` (rwycc, depthMm, grooved, rolling μ ต่อชนิดผิว) อยู่ใน `Flight` และผูกกับพิกัดผ่านข้อมูลสนามบินภายหลัง
2. **State vector 13 → 22:** `x[13..15]` stroke, `x[16..18]` ระยะเบี่ยงด้านข้างของยาง $y$, `x[19..21]` ระยะ bristle ตามยาว $x_b$ หลังแต่ละ RK4 step ทำ projection (clamp) ทั้งสามกลุ่ม ค่าที่ไม่ต่อเนื่อง (ธงล้อล็อก, ω ของ spin-up, อุณหภูมิเบรก, มุม caster) อัปเดตนอก RK4 ครั้งละ step
3. **ลำดับต่อหนึ่งล้อใน `deriv()`:** หา pen และ ṗen ตามแนวตั้งฉากพื้น → `strutStep` ได้ N และ ṡ → หาความเร็วจุดสัมผัสในระนาบล้อ ($v_l, v_s$) → `surfaceMu` → แรงเบรก/ล้อล็อก (7.4) → แรงด้านข้างจาก $y$ จำกัดด้วยวงกลมแรงเสียดทาน → แปลงกลับเป็น NED และโมเมนต์รอบ CG (แขนโมเมนต์ใช้ stroke จริง)
4. **รายงานให้ HUD/Evaluator:** แรงที่ล้อ, stroke, $n_g$ สูงสุดตอนแตะ, ธง hydroplaning/ล้อล็อก (เสียงยาง ควัน), อุณหภูมิเบรก
5. **ความเข้ากันได้:** `setParked()` เริ่ม stroke ที่จุดสมดุลสถิต, `setApproach()` ตั้ง stroke = 0, autopilot (บรรทัด 418) เปลี่ยนเบรก 0.42 เป็นเป้าค่าหน่วงเพราะ μ เปลี่ยนตามผิว
6. **ต้นทุน (ค่าประมาณ):** ราว 60 การคำนวณจุดลอยต่อล้อต่อ stage × 3 ล้อ × 4 stage × 240 Hz ≈ 170,000 ครั้งต่อวินาทีจำลอง น้อยกว่า 1 ms ต่อวินาทีบนเบราว์เซอร์ทั่วไป ไม่กระทบ frame budget

## 7.10 ความขัดแย้งของแหล่งข้อมูลและข้อจำกัด
- **ความแข็งด้านข้างของยาง:** NACA TN 4110 ให้ประมาณ 3.2 /rad (0.056 /deg) สำหรับยาง 6.50-8 ที่เราเลือก [G9] ส่วนค่าเริ่มต้นของ JSBSim (Magic Formula B 0.06, C 2.8, D 0.8, E 1.03) ให้ 7.7 /rad [G19] ต่างกัน 2.4 เท่า เราเลือกค่าจาก NASA เพราะเป็นข้อมูลยางเครื่องบิน แต่ OCR ของสูตรไม่ชัด จึงให้ความเชื่อมั่นต่ำถึงกลาง ควรปรับตามความรู้สึกตอนแตะพื้นแบบ crab
- **Relaxation length:** สัมประสิทธิ์ในสูตร TN 4110 eq. 43 อ่านได้ทั้ง 0.55 และ 5.5 ให้ 0.35 หรือ 0.24 m [G9] การอ่านซ้ำในการตรวจทานเห็น ".55" จึงเอนไปทาง 0.35 m แต่ยังไม่ได้เทียบกับภาพสแกน
- **แรงตอนล้อแตะ (แก้ในการตรวจทาน):** code ฉบับแรกของ `strutStep` ให้ N กระโดด 1.19 W_st ทันทีที่แตะ เพราะ damping ยางไม่ถูกจำกัด จึงแก้ให้ $|c_t\dot\delta| \le k_t\delta$ ตัวเลขใน 7.2 และ T-G-03 ถึง T-G-07 คำนวณใหม่แล้ว
- **การเลี้ยวด้วยแป้นที่ความเร็วสูง:** ข้อเสนอ 12° คงที่ให้ $a_y$ 0.73 g ที่ 10 m/s (ค่าประมาณ) จึงเป็นเรื่องเทคนิคการบินและ ASSIST ไม่ใช่สิ่งที่โมเดลยางแก้ได้
- **RWYCC 1 และ 0:** น้ำแข็ง FAA ใช้ 0.08 [G13] EASA ใช้ 0.07 [G15]; รหัส 0 ICAO เรียก "LESS THAN POOR" [G16] FAA เรียก "Nil" [G13] UI ควรใช้คำของ ICAO ตามที่ กพท. ใช้ [G17]
- **Hydroplaning ของยางที่ไม่หมุน:** NASA TM X-72650 ให้ 7.7√p [G11] ขณะที่ AC 25-32 ใช้ 9√p กับตัวคูณ 0.85 (= 7.65√p) [G13] สองค่านี้ใกล้กันมากจนใช้แทนกันได้
- **Part 23 ปัจจุบันไม่มีตัวเลข drop test แล้ว:** ค่าที่ใช้มาจากฉบับปี 2016 [G3–G5] จึงเป็นเป้าทางวิศวกรรม ไม่ใช่เกณฑ์รับรองปัจจุบัน สูตร $W_e$ ของ 23.725(b) อ่านจากต้นฉบับไม่ได้ (เป็นรูปภาพ) เราเขียนใหม่จากการเทียบพลังงานและตรวจสอบกับข้อความ 23.727(b) ที่อ่านได้
- **สมการ 25.109(c)/(d):** PDF ของ govinfo แสดงเป็นรูปภาพ ค่าสัมประสิทธิ์อ่านจาก LII [G6] ตรวจความสมเหตุสมผลแล้ว (ทางเรียบ 50 psi ที่ 0 kt = 0.883 และ grooved สูงกว่าทางเรียบทุกความเร็ว) แต่ยังควรเทียบกับ eCFR อีกครั้งเมื่อเข้าถึงได้ (ความเชื่อมั่นของ (c) สูง ของ (d) กลาง เพราะเลขชี้กำลังสร้างใหม่จากเลย์เอาต์)
- **NACA Rep. 1154** อ่านผ่านสำเนา OCR (NTRS ดาวน์โหลดไม่ได้จากเครื่องมือ) ค่า n = 1.12 และ C_d = 0.9 ยกมาจากข้อความตรง ส่วนรูปสมการไฮดรอลิกตรงกับตำราทั่วไป
- **ค่าของเครื่องฝึก (stroke, ความดัน, K_h, ยาง, เบรก, มุมเลี้ยว)** เป็นค่าที่ออกแบบเองทั้งหมด (`est: true`) ไม่ได้มาจากเครื่องบินจริงแบบใด ข้อมูลยางเป็นค่าจริงของผู้ผลิต แต่การเลือกยางเป็นของเรา
- **ยังไม่ยืนยัน:** มุมไทลเลอร์/แป้นและ autobrake ของ airliner, และผิว grooved ของทางวิ่ง VTBD (AIP AD 2.12)
