# สคริปต์คำนวณของรอบที่ 1

← [กลับไปหน้ารวมรอบที่ 1](../../01-flight-physics.md)

โฟลเดอร์นี้เก็บสคริปต์ที่ผู้วิจัยและผู้ตรวจทานใช้คำนวณตัวเลขในรายงานรอบที่ 1 และผลคาดหวังของกรณีทดสอบ เป็นหลักฐานการคำนวณ ไม่ใช่โค้ดของแอป ไม่ถูก build และไม่ถูกรันใน CI ไฟล์ในโฟลเดอร์นี้ไม่ควรถูกแก้เพื่อใช้งานจริง เมื่อจะ implement ให้เขียนโค้ดใหม่ใน `src/` และ `test/` ตามรายงาน

## วิธีรัน

- สคริปต์ส่วนใหญ่เป็น Node ≥ 18 ไม่มี dependency ให้รันจากรากของ repo เช่น `node docs/research/01-flight-physics/scripts/g7_current.mjs` สคริปต์หลายตัวโหลด `src/10-atmo.js`, `src/15-geo.js` และ `src/20-flight.js` แบบเดียวกับ `test/harness.mjs` ผลจึงขึ้นกับโค้ด ณ commit `cabf0f0`
- path ในสคริปต์ถูกแปลงให้อ้างจากรากของ repo แล้ว แต่สคริปต์เขียนขึ้นระหว่างค้นคว้า บางตัวอาจต้องปรับ path หรือรันตามลำดับ (ตัวที่สร้างไฟล์ `.json` ก่อนตัวที่อ่าน) ถ้ารันไม่ได้ ให้ยึดตัวเลขที่บันทึกไว้ในรายงาน
- `s9_eigen.mjs` ใช้ `ml-matrix` 6.12.1 (MIT) ต้องติดตั้งเองในโฟลเดอร์ชั่วคราว ไม่ได้เพิ่มเป็น dependency ของ repo
- สคริปต์ Python ใน `s12/` ใช้แพ็กเกจ `jsbsim` 1.3.3 จาก PyPI (LGPL-2.1) ติดตั้งด้วย `pip install jsbsim==1.3.3` ไฟล์ `s12/oracle_*.json` เป็นผลการบินของ JSBSim ที่บันทึกไว้เพื่อใช้เป็น fixture ใน Node โดยไม่ต้องติดตั้ง JSBSim
