# สคริปต์คำนวณของรอบที่ 3

← [กลับไปหน้ารวมรอบที่ 3](../../03-airliners.md)

สคริปต์ทั้งหมดในโฟลเดอร์นี้ใช้ Node ≥ 18 อย่างเดียว ไม่มี dependency และไม่ต่อเน็ต (ค่าจากแหล่งถูกพิมพ์ไว้ในสคริปต์พร้อมรหัสแหล่ง) รันจากโฟลเดอร์นี้ได้เลย เช่น `node k_flare.mjs` ไฟล์ `*_out.txt` และ `*_out.md` คือผลลัพธ์ที่บันทึกไว้ตอนค้นคว้า ใช้เทียบเมื่อรันซ้ำ

สคริปต์ทุกตัวเป็นงานที่เขียนขึ้นในโครงการนี้และเป็นของเจ้าของ repo (repo ยังไม่มีไฟล์ LICENSE) ค่าที่ลอกมาจากโมเดลเปิด (FlightGear GPL-2.0, JSBSim LGPL-2.1, OpenAP/WRAP LGPL-3.0, FlyByWire GPL-3.0) ใช้เป็นตัวเลขเทียบเท่านั้น ไม่ได้คัดลอกโค้ดของโครงการเหล่านั้น รายละเอียดอยู่ในตารางสัญญาอนุญาตของหน้ารวม

## สคริปต์รวม

| ไฟล์ | หน้าที่ |
|---|---|
| `r3_merge.mjs` | ดึงบล็อก JSON จากไฟล์หัวข้อทั้ง 10 ไฟล์ ตรวจรูปแบบ leaf และสิทธิ์ของหัวข้อตาม [schema-ext.md](../schema-ext.md) ข้อ 4 รวมตามแบบเครื่องบิน แก้ `_inherits` แล้วเขียน `params-<แบบ>.json`, `params-common-airliner.json` และ `merge-report.json` (ข้อผิดพลาด คำเตือน path ที่ชนกัน และความครอบคลุมเทียบกับรอบที่ 1) |
| `r3_schema.mjs` | สร้าง [schema.md](../schema.md) ตารางค่าทุก path ของทุกแบบเทียบกัน จาก `params-*.json` และ `merge-report.json` |
| `r3_refs.mjs` | จัดกลุ่มแหล่งอ้างอิงทุกรายการในไฟล์หัวข้อตามสัญญาอนุญาต (ใช้ทำตารางสัญญาอนุญาตในหน้ารวม) `--unk` พิมพ์รายการที่จัดกลุ่มไม่ได้ |
| `r1-pertype-paths.json` | รายการ path รายแบบ 384 path ของรอบที่ 1 ที่ `r3_merge.mjs` ใช้นับความครอบคลุม |

สร้างไฟล์รวมใหม่หลังแก้ไฟล์หัวข้อ (รันจากโฟลเดอร์ `docs/research/03-airliners/`):

```
node scripts/r3_merge.mjs --dir . --out .
node scripts/r3_schema.mjs
```

`r3_merge.mjs --dry` ตรวจอย่างเดียวไม่เขียนไฟล์ และ `--coverage` พิมพ์ path ของรอบที่ 1 ที่ยังขาดทีละบรรทัด
