# tools/watch: เฝ้ารอบ AIRAC, SUP/AIC และทะเบียนอากาศยาน

แผนพัฒนาข้อ A10 (งานวิจัย R2-09, R5-P3-7, R5-S1-8) ให้รู้ทันเมื่อ AIP Thailand หน้า AD 2 VTBD หรือทะเบียนอากาศยานของ กพท.
เปลี่ยน และเก็บบันทึกว่าอ่าน AIP SUP และ AIC ฉบับใดแล้ว สคริปต์ใช้เครือข่ายจึงไม่อยู่ใน CI ส่วนที่ไม่ใช้เครือข่าย (ตัวอ่านหน้า
ตัวเทียบ ตัวตรวจค่า และตัวแยกแถวทะเบียน) มีเทสต์ใน `test/watch.test.mjs` และ `test/register.test.mjs` ที่ CI รันทุกครั้ง

Node ≥ 22 ไม่มี dependency ดาวน์โหลดด้วย `curl` ของระบบ (ใช้ `HTTPS_PROXY` ได้) รันจากรากของ repo

## คำสั่ง

| คำสั่ง | ทำอะไร | เครือข่าย |
|---|---|---|
| `node tools/watch/watch.mjs aip` | อ่านดัชนี eAIP (https://aip.caat.or.th/) แล้วเทียบ AD 2 VTBD ของทุกฉบับที่ใหม่กว่าฉบับของ repo กับฉบับก่อนหน้าทีละหัวข้อ ตรวจทุกค่าใน `test/fixtures/aip_vtbd_current.json` กับข้อความของแต่ละฉบับ อ่านรายการแก้ไข (AMDT) และรวบรวม SUP/AIC จากรายการของฉบับที่มีผลอยู่ ฉบับใหม่สุด และปกของฉบับที่ใหม่กว่า แล้วเทียบกับ `reviewed.json` | ใช้ |
| `node tools/watch/watch.mjs due` | วัน AIRAC ถัดไป วันต้องตรวจซ้ำ (`meta.recheck_before` ของ fixture) และกำหนดของทะเบียน | ไม่ใช้ |
| `node tools/watch/watch.mjs register --pdf <ไฟล์>` | แยกแถวทะเบียนจาก PDF (ใช้ `pdftotext -layout` ของ poppler) เทียบกับฉบับที่ commit ไว้ แล้วให้ `ls_fleet.mjs --register ... --check` บอกว่าบล็อก §02.6 จะเปลี่ยนไหม | ไม่ใช้ (ยกเว้นตอนไม่ให้ไฟล์) |
| `node tools/watch/watch.mjs all` | `aip` แล้วตามด้วยกำหนดของทะเบียน (หรือ `register` เต็มเมื่อให้ `--pdf`/`--text`) | ใช้ |

ตัวเลือกหลัก: `--out <dir>` (รายงานและแคช ค่าเริ่มต้น `.cache/watch/` ซึ่ง git ไม่เก็บ), `--from <dir>` (อ่านหน้าจากโฟลเดอร์แทน
เครือข่าย), `--refresh` (ดาวน์โหลดใหม่), `--research` (รัน `ls_aip_check.mjs` และ `lo_aip_check.mjs` ของงานวิจัยรอบ 2 กับฉบับที่ใหม่
กว่าด้วย ผลอยู่ใน `<out>/research/out/` ไฟล์ใน repo ไม่เปลี่ยน), `--today YYYY-MM-DD` ดูทั้งหมดด้วย `--help`

Exit: **0** ไม่มีอะไรต้องทำ · **1** ต้องมีคนอ่านหรือแก้บางอย่าง (ข้อความบอกว่าอะไร) · **2** ตัดสินไม่ได้ (เครือข่ายหรืออ่านหน้าไม่ได้)

รายงานเต็ม (`report-aip-<วันที่>.md` และ `.json`) และหน้าที่ดาวน์โหลดอยู่ใน `.cache/watch/` ห้าม commit เพราะมีข้อความ AIP
(ลิขสิทธิ์ CAAT) repo เก็บเฉพาะตัวเลขใน fixture และบันทึกด้วยคำของเราเองใน `reviewed.json`

## ข้อมูลที่สคริปต์อ่าน

- **รอบ AIRAC**: `test/fixtures/aip_vtbd_current.json` → `meta.airac_effective` คือฉบับที่ repo อ้าง (footer, `src/15-geo.js`, CLAUDE.md
  ตาม T-K05) ฉบับใน `meta.next_issues` ถือว่าตรวจแล้ว และ `meta.recheck_before` คือวันมีผลของฉบับถัดไปที่ยังไม่ได้ตรวจ ฉบับ AIRAC
  เผยแพร่ล่วงหน้า 42 วัน `due` จึงเตือนตั้งแต่วันที่ฉบับนั้นเผยแพร่
- **SUP/AIC**: `tools/watch/reviewed.json` หนึ่งรายการต่อฉบับ (`sup` คีย์ `A25/26`, `aic` คีย์ `07/26`) ช่องบังคับ `read` (วันที่อ่าน),
  `basis` (`text` = เปิดอ่านเนื้อหาแล้ว, `title` = ตัดสินจากชื่อเรื่อง ใช้ได้เฉพาะเมื่อชื่อเรื่องระบุสนามอื่นและไม่มี Bangkok หรือ VTBD),
  `vtbd` (true/false) และ `note` (ภาษาไทย คำของเราเอง) ช่องเสริม `folder`, `in`, `until` (วันที่, `UFN` หรือ `PERM`), `status`, `repo`
  (ผลต่อ repo) ห้ามคัดลอกชื่อเรื่อง และห้ามใส่ชื่อหน่วยทหาร โรงเรียน หรือสถาบันของทหาร (สนามทหารเขียนแค่รหัส ICAO)
  `test/watch.test.mjs` ตรวจรูปแบบไฟล์นี้ทุกครั้ง
- **ทะเบียนอากาศยาน**: ไฟล์ `docs/research/02-light-aircraft/scripts/out/ls_register_<วันที่>.json` ที่ใหม่สุด (วันนี้ฉบับ 9 ก.ค. 2026)

## เมื่อมีรอบ AIRAC ใหม่

ฉบับ AIRAC 21 JAN 2027 เผยแพร่ราว 10 DEC 2026 จากนั้นทุก 28 วัน (ตารางปี 2027 อยู่ใน AIC 07/26)

1. `node tools/watch/watch.mjs aip` ถ้า exit 1 เพราะมีฉบับใหม่ที่ยังไม่บันทึก สคริปต์พิมพ์ JSON สำหรับ `meta.next_issues` และวัน
   `recheck_before` ถัดไปให้
2. ถ้า AD 2 VTBD ไม่เปลี่ยนและค่าใน fixture ผ่านทุกค่า: เพิ่มรายการนั้นใน `meta.next_issues` แก้ `meta.recheck_before` แล้วรันอีกครั้ง
   ให้ได้ exit 0
3. ถ้ามีหัวข้อเปลี่ยนหรือค่าไม่ผ่าน: อ่านรายงานเต็ม แก้ค่าใน fixture ก่อน (ตามที่ CLAUDE.md กำหนด) แล้ว `test/aip.test.mjs` และ
   `test/licenses.test.mjs` จะบอกว่าต้องแก้ `RWY_DATA` ข้อความใน UI หรือ footer ตรงไหน ถ้าค่าที่ใช้ในฉากเปลี่ยน ให้ทำใน PR แยก
4. เมื่อ repo เปลี่ยนไปอ้างฉบับใหม่ ให้รัน `aip --research` ด้วย (R2-09: `ls_aip_check.mjs` และ `lo_aip_check.mjs`, T-LS-10, T-LS-12,
   T-LO-33, T-LO-34) ถ้ารหัสพื้นที่ฝึกหรือข้อความที่สองสคริปต์นี้ตรวจเปลี่ยน ให้แก้ค่าคาดหวังในสคริปต์และรายงานรอบ 2

## เมื่อมี SUP/AIC ใหม่

`aip` แยกรายการที่ยังไม่บันทึกเป็น `vtbd` (ชื่อเรื่องพูดถึง VTBD/Don Mueang), `unclear` (เรื่องทั้ง FIR, GNSS, ตาราง, ค่าธรรมเนียม ฯลฯ)
และสนามอื่น สองแบบแรกต้องเปิดอ่านเนื้อหาก่อน (exit 1) แบบสุดท้ายเป็นข้อมูลเท่านั้น สคริปต์พิมพ์โครง JSON ให้กรอก `note` ด้วยคำของเราเอง
รายการที่ `vtbd: true` และยังมีผล สคริปต์จะเตือนทุกครั้งให้ดูว่า repo ต้องทำอะไร

## เมื่อมีทะเบียนอากาศยานฉบับใหม่

กพท. ออกทะเบียนราวปีละสองครั้ง (ฉบับ as at 14 Jan 2026 และ 9 Jul 2026; ฉบับถัดไปคาดราวต้นปี 2027 เป็นค่าประมาณ) แต่
www.caat.or.th กันการดาวน์โหลดอัตโนมัติด้วย Cloudflare และ WebFetch ได้แค่ข้อความที่ถูกตัด จึงต้องโหลดด้วยมือ

1. เปิดหน้าทะเบียนอากาศยานของ กพท. ในเบราว์เซอร์ ดาวน์โหลด PDF "Thailand Aircraft Register as at ..." ฉบับใหม่สุด แล้วอัปโหลดเข้า
   โปรเจกต์ (หรือวางไว้ที่ใดก็ได้นอก repo; ห้าม commit PDF)
2. `node tools/watch/watch.mjs register --pdf <ไฟล์>` สคริปต์คัดเครื่องปีกตรึงของโรงเรียนการบินและชมรมที่ `ls_fleet.mjs` รู้จัก เขียน
   `.cache/watch/register/ls_register_<วันที่>.json` แล้วรายงานเครื่องที่เพิ่ม หาย หรือเปลี่ยน ผู้ดำเนินการที่ชื่อคล้ายโรงเรียนแต่ยังไม่รู้จัก
   รุ่นที่ `ls_fleet.mjs` ยังจัดแบบไม่ได้ และแถวที่แยกคอลัมน์ไม่ได้
3. ถ้ายอมรับฉบับใหม่ (ทำใน PR ของงานวิจัย): คัดลอกไฟล์แถวเข้า `docs/research/02-light-aircraft/scripts/out/` แก้ไฟล์ค่าเริ่มต้นและ `AS_OF`
   ใน `ls_fleet.mjs` ให้เป็นฉบับใหม่ (เพิ่มผู้ดำเนินการใน `OPS` และรุ่นใน `classify` ถ้ามี) รัน `ls_fleet.mjs --write` แก้ตัวเลขใน
   `02-thai-schools.md` และค่าคาดหวังของ `ls_tests.mjs` แล้ว `node docs/research/02-light-aircraft/scripts/lm_ci.mjs --root .` ต้องผ่าน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `watch.mjs` | คำสั่ง `aip`, `due`, `register`, `all` |
| `lib.mjs` | ส่วน pure: อ่านดัชนี ปก รายการ SUP/AIC และ AMDT, รอบ AIRAC, แบ่งหัวข้อ AD 2, เทียบข้อความ, ตรวจค่าจาก fixture, จัดกลุ่มชื่อเรื่อง, ตรวจ `reviewed.json` |
| `net.mjs` | ดาวน์โหลดด้วย curl และแคช (โหลดใหม่เมื่อฉบับที่เก็บไว้ก่อนวันมีผลถึงวันมีผลแล้ว) |
| `register.mjs` | ทะเบียนอากาศยาน: `runRegister`, `registerDue`, ตัวแยกแถวสองรูปแบบ (`pdftotext -layout` และข้อความต่อบรรทัดเดียว) |
| `reviewed.json` | บันทึก SUP/AIC ที่อ่านแล้ว (อ่านครั้งแรก 26 พ.ย. 2026: SUP 75, AIC 11) |
